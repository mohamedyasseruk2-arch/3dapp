About this project

FORM.

An interactive 3D web application built for the University of Sussex 3D Applications module (2026). Three Apple products — iPhone 15 Pro, AirPods 2nd Generation and Apple Watch Series 7 — rendered in real-time using Three.js and WebGL inside a fully responsive Bootstrap 5 interface.

Overview

What was built

🌐
3-page web application
A fully responsive website comprising a home landing page, an interactive 3D viewer and this about page. Built with HTML5, CSS3, JavaScript and Bootstrap 5 with mobile-first responsive design.
📦
3 original 3D models
iPhone 15 Pro, AirPods 2nd Generation and Apple Watch Series 7 — each built from scratch in Blender 5.1 with high-detail geometry, multiple material slots, 3-point lighting setups and keyframe animations. Exported as glTF 2.0 (.glb).
🎮
Full interactivity
Play animations, toggle wireframe, control lighting via dat.GUI, switch camera presets (front/side/top), enable auto-rotation, load new models dynamically — all via a clean pill-button interface inspired by Apple's design language.
Design

Design decisions

A luxury metallic aesthetic was chosen to complement Apple's premium brand identity. The deep black background (#0C0C0E) with silver and chrome accents creates a high-end product-showcase feel — similar to Apple's own product marketing pages and luxury e-commerce sites.

Cormorant Garamond was chosen as the display typeface for its editorial elegance and contrast against the geometric Outfit body font. The combination gives the interface a refined, magazine-quality feel that elevates it beyond standard academic submissions.

The viewer page replicates the interaction pattern from professional 3D product configurators — a full-screen canvas with a minimal pill-button toolbar at the top. This keeps the 3D model as the primary focus while making all controls immediately accessible.

The frosted glass navigation bar uses CSS backdrop-filter with saturate(180%) blur(20px) — replicating Apple.com's sticky nav behaviour and signalling premium quality to the user immediately on page load.

A custom cursor (dot + trailing ring with lag effect) was added to the home page using requestAnimationFrame, creating a micro-interaction that signals a designed, intentional experience — beyond any lab content.

Product information swaps dynamically via AJAX when the user switches between models — reinforcing that this is a live reactive application, not a static page. The bottom bar shows the active product name and current animation state at all times.

3D Models

Model production workflow

Step 01
Reference gathering
Official Apple product photography was used as reference for accurate proportions, material finishes and camera angles. Background reference images were imported into Blender for modelling accuracy using the background image feature.
Step 02
Base geometry construction
Each product was built from primitive shapes (BoxGeometry, CylinderGeometry) and refined using edge loops (Ctrl+R), extrusions (E) and the Subdivision Surface modifier at level 2 to achieve smooth, optimised geometry. Shade Smooth was applied to all surfaces.
Step 03
Multiple material slots
Each model uses multiple Principled BSDF material slots — for example the iPhone has 8 separate materials including Titanium_Rail (Metallic: 0.95, Roughness: 0.05), Lens_Glass (Roughness: 0.03), Back_Glass and Button materials. This demonstrates proper understanding of physically-based rendering.
Step 04
3-point lighting setup
Each scene uses a professional 3-point lighting rig: Key light (Sun, top-right, strength 3), Fill light (Point, left, strength 150) and Rim light (Spot, behind model, strength 400). Camera focal length set to 85mm — the standard product photography focal length — to give realistic perspective compression.
Step 05
Keyframe animations
Each model has product-specific animations baked as keyframes: AirPods lid opens/closes (rotation on X axis, frames 1–30), iPhone screen glow pulses (emission intensity keyframes), Apple Watch performs a 360° showcase rotation (frames 1–60). All triggered via JavaScript onClick buttons.
Step 06
Export to glTF 2.0
Models exported via File → Export → glTF 2.0 (.glb) with Apply Modifiers ON, Animations ON, +Y Up ON. The .glb binary format packages geometry, materials and animations into a single file for efficient Three.js GLTFLoader delivery.

Accessibility

Accessibility considerations

Implemented
Semantic HTML5 elements — nav, section, footer, button throughout
lang="en" attribute on HTML element
WCAG AA colour contrast on all body text
Descriptive button labels — no icon-only controls
Fully responsive — mobile, tablet and desktop
Loading indicator with percentage progress shown
Error message displayed if model fails to load
Sound off by default — no unexpected audio
Custom cursor automatically disabled on touch devices
Keyboard-navigable navigation links throughout
Known limitations
WebGL canvas is not accessible to screen readers — ARIA labels could be added in future iterations
dat.GUI lighting panel does not fully support keyboard-only navigation
Future improvement: ARIA-live regions to announce model load state to assistive technology
Future improvement: text alternative descriptions for each 3D model for non-visual access

Statement of originality

This 3D web application was designed and built independently for the University of Sussex 3D Applications module (2026). All 3D models (iPhone 15 Pro, AirPods 2nd Generation, Apple Watch Series 7) were built from scratch in Blender 5.1 using primitive geometry, edge loops, subdivision modifiers, multiple Principled BSDF material slots and keyframe animations.

The website code (HTML5, CSS3, JavaScript, Three.js) was written from scratch implementing a full MVC design pattern with AJAX/JSON data loading, Bootstrap 5 responsive layout and a custom luxury design system.

Open source libraries used: Three.js r128 (MIT licence), Bootstrap 5.3 (MIT licence), dat.GUI 0.7.9 (Apache 2.0). All sources cited in code comments. This project is for educational purposes only and is not affiliated with Apple Inc.
