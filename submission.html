Evidence 05
Deeper Understanding Statement with testing feedback

Features beyond lab tutorials demonstrated in this project:

1. MVC Architecture — viewer.html implements a full Model-View-Controller design pattern with three completely separate JavaScript objects: AppModel (manages all 3D state, product data and Three.js objects), AppView (handles all DOM updates, tab building and loading states) and AppController (manages all event logic, model loading and animation). This goes significantly beyond the lab approach of inline scripting.

2. AJAX / JSON data loading — Product data is loaded dynamically from products.json using XMLHttpRequest with a full fallback for offline/server environments. This demonstrates asynchronous data loading and separation of data from presentation — beyond any lab content.

3. Bootstrap 5 beyond lab level — Full responsive 3-column grid layout with custom breakpoints, frosted glass navigation using CSS backdrop-filter saturate(180%) blur(20px), scroll-triggered fade animations via IntersectionObserver, and a marquee animation component.

4. Advanced Three.js rendering — ACES Filmic tone mapping (renderer.toneMapping = THREE.ACESFilmicToneMapping), PCFSoft shadow maps, 4-point lighting setup (ambient hemisphere, key directional, fill directional, rim directional, controllable spotlight), and Three.js AnimationMixer for glTF animation playback.

5. GitHub version control — Complete codebase managed via GitHub Desktop with full commit history. Public repository accessible to markers at the URL above. Using GitHub for codebase management as specified in the assignment brief.

6. URL parameter routing — viewer.html reads ?product= URL parameters to load specific models when navigating from home page product tiles, creating a proper client-side routing pattern not covered in labs.

7. Luxury design system — Custom design language with CSS variables, Cormorant Garamond display font, metallic gradient text effects, custom cursor with requestAnimationFrame lag effect, chrome divider lines with gradient opacity — all original design decisions beyond any lab content.

Testing feedback: Tested in Chrome, Edge and Firefox. Responsive layout verified at 375px, 768px, 1366px and 1920px. All 9 control buttons verified functional. Product switching, wireframe toggle, lighting GUI, camera presets, auto-rotate and animation all confirmed working correctly. Models load under 3 seconds. 60fps maintained throughout. No console errors on final build.
